# 📚 Signals and Systems (`EAEPC302`)

> **Department / Degree**: ECE / EE / ICE / ECAM · NSUT
> **Course Overview**: Continuous and discrete-time signals, LTI systems, convolution, Fourier Series & Transforms (CTFT/DTFT), Laplace Transform, Z-Transform, and system stability/frequency response.
