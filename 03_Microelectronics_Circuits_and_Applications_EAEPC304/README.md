# 📚 Microelectronics Circuits and Applications (MCA) (`EAEPC304`)

> **Department / Degree**: ECE / EE / ICE / ECAM · NSUT
> **Course Overview**: Semiconductor physics review, MOSFET & BJT small-signal models, single-stage & multi-stage amplifiers, frequency response, current mirrors, differential amplifiers, feedback topologies, and Op-Amp internal circuitry.
