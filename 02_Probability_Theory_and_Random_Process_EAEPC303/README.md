# 📚 Probability Theory and Random Process (PTRP) (`EAEPC303`)

> **Department / Degree**: ECE / EE / ICE / ECAM · NSUT
> **Course Overview**: Axiomatic probability, random variables (1D & 2D), probability distributions (Gaussian, Poisson, Exponential, etc.), expectation, moments, transformations, Random Processes, stationarity, autocorrelation, Power Spectral Density (PSD), and transmission through LTI systems.
