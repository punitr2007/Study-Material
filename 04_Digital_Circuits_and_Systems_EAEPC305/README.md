# 📚 Digital Circuits and Systems (DCS) (`EAEPC305`)

> **Department / Degree**: ECE / EE / ICE / ECAM · NSUT
> **Course Overview**: Boolean algebra, logic gate minimization (K-Maps, Quine-McCluskey), combinational logic design (multiplexers, decoders, adders, ALUs), sequential circuits (latches, flip-flops, registers, counters), finite state machines (Mealy/Moore FSMs), timing analysis, semiconductor memories (ROM/RAM/PLA), and introduction to HDL (Verilog).
