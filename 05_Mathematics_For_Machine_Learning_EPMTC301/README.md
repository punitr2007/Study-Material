# 📚 Mathematics For Machine Learning (MML) (`EPMTC301`)

> **Department / Degree**: Mathematics / Computing / ECE / CSAI · NSUT
> **Course Overview**: Linear Algebra (vector spaces, inner products, eigenvalues/eigenvectors, SVD, PCA), Multivariate Calculus (gradients, Jacobian, Hessian, automatic differentiation), Optimization (gradient descent, Newton methods, convex optimization, Lagrange multipliers), and Probability & Statistics for Data Modeling (Maximum Likelihood Estimation, MAP, Bayesian inference).
