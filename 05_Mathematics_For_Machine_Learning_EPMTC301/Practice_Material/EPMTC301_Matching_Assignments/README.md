# EPMTC301 Matching Practice Materials

This directory contains targeted practice assignments directly aligned with the three **EPMTC301 Problem Sheets** (Mathematics for Machine Learning):

---

## 📂 Sheet-Wise Mapping

### 1. Problem Sheet 1: Subspaces, Basis, Linear Independence
*(Axler Chapter 1 / Strang Chapters 2–3)*
- **Purdue Math 353 Practice Midterm 1**: True/False & multiple choice on subspaces of $\mathbb{R}^3$, basis questions, linear transformations.
- **Dartmouth Math 225 Midterm Review**: Axiomatic subspace proofs, linear independence, basis construction.
- **HSC Math 231 Midterm 2 Review**: Null space, row space, column space, dimension computations.

### 2. Problem Sheet 2: Linear Transformations, Kernel, Image, Invertibility
*(Axler Chapter 2 / Strang Chapter 7)*
- **Northeastern Sp26 Advanced LA Midterm 1 Review (Problems & Answers)**: Finding bases for $\ker(T)$ and $\operatorname{im}(T)$ for maps on $\mathbb{R}^3, \mathcal{P}_2(\mathbb{C}), \mathcal{M}_{2\times 2}(\mathbb{R})$.
- **Cologne University Kernel & Image Exercise Sheet**: Subspace proofs for image/kernel, abstract polynomial maps.

### 3. Problem Sheet 3: Eigenvalues, Inner Products, Gram-Schmidt
*(Strang Chapter 6 / Axler Chapter 5–6)*
- **TCD Dublin MA1112 Past Exams**: Gram-Schmidt orthogonalization on polynomial spaces $\mathcal{P}_2(\mathbb{R})$ using integral inner products $\langle f,g \rangle = \int f(t)g(t)\,dt$.
- **Politecnico Torino Exercise Sheet 9**: Gram-Schmidt in $\mathbb{R}^4$, eigenvalues/eigenvectors of polynomial maps, orthogonal diagonalization.
